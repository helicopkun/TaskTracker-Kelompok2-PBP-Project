Task Tracker merupakan website yang menyimpan detail dan tenggat dari tugas/task yang belum dikerjakan, sekaligus memiliki fitur 'Team' untuk sekelompok user yang memiliki tugas bersama.

Fitur:
    Tambah task
    Update task
    Riwayat task
    Team

Cara menjalankan 
1. Masuk live server website dengan link https://tasktracker-kelompok2-pbp-project.vercel.app/

2. Jika ingin melalui localhost, maka: 
    1. Clone repo
    2. Terminal > npm install
    3. Buat file di root directory dengan nama '.env' yang memiliki isi: 
    DATABASE_URL = "postgresql://postgres.olxrdxiemggeanofjkkn:[DB-PASSWORD]@aws-1-ap-southeast-1.pooler.supabase.com:6543/postgres"
    4. Request password DB dari saya
    5. Localhost siap dijalankan

    Lalu, Terminal > node index.js
